# InnoColor Edge - Windows deployment

Windows deployment branch. Adds TCS3472 RGB ambient light sensor support that
the Linux deployment lacks, via `rgb_sensor_print.ino.ino` (microcontroller
firmware) and `rgb_sensor_display.py` (host-side readout).

Full documentation - installation, version lineage, usage - lives on
[`main`](https://github.com/Brocoliman/InnoColor/blob/main/README.md). Follow
the Windows-specific steps noted there.
